BOODSCHAPPEN & RECEPTEN - VEILIGE PWA

Deze app:
- gebruikt geen account of database;
- bevat geen analytics, advertenties of externe scripts;
- verstuurt de boodschappenlijst of vinkjes niet naar derden;
- bewaart vinkjes lokaal in de browser op het apparaat;
- gebruikt een Content Security Policy die externe verbindingen blokkeert.

Let op:
De hostingprovider kan technisch gezien normale webserverlogs bijhouden
(bijvoorbeeld IP-adres en tijdstip van bezoek). De appcode zelf stuurt geen
boodschappen- of receptgegevens naar een server.

INSTALLATIE VIA GITHUB PAGES
1. Maak een nieuw repository aan op GitHub.
2. Upload index.html, manifest.json en sw.js uit deze map.
3. Open Settings > Pages.
4. Kies Deploy from a branch, branch main, map /(root).
5. Open daarna de HTTPS-link op de iPhone in Safari.
6. Tik Delen > Zet op beginscherm > Voeg toe.

Gebruik alleen de HTTPS-link die bij jouw eigen repository hoort.
